# Plourg

Plourg is a campus‑focused marketplace where people can buy, sell, and connect with trusted local vendors. Join the waitlist to get early access and help shape the platform.

## Highlights

- Early access for campus vendors and shoppers
- Discover vendors and services around campus
- Place orders, connect instantly, or pick up with zero hassle
- Stay updated with exclusive launch news

## Tech Stack

- Next.js 15, React 19, TypeScript
- Tailwind CSS, Framer Motion
- AOS, Sonner

## Development

```bash
pnpm dev # or npm run dev / bun dev / yarn dev
```
